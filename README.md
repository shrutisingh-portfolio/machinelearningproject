# End to End Machine Learning Project
- Developed a complete machine learning pipeline including data ingestion, preprocessing, model training, evaluation, and prediction.
- Built a Flask-based web application for real-time inference.
- Implemented modular architecture with logging, exception handling, and reusable components.
- Automated build and deployment workflows using CI/CD pipelines.
- Deployed the application on AWS cloud infrastructure for scalable access.
- Utilized Git and GitHub for version control and collaborative development.
